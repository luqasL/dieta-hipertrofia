# Dieta Hipertrofia

Painel pessoal para acompanhar a dieta de ganho de massa: calorias e macros de cada refeição, média dos últimos 7 dias, peso semanal com a meta de ganhar de 0,5 a 1 kg por mês, e metas que se ajustam ao peso.

**Link do site:** https://luqasl.github.io/dieta-hipertrofia/

## Como funciona

- É um arquivo só (`index.html`), sem servidor. Abre no navegador do celular ou do computador.
- Os registros ficam salvos no próprio navegador. Cada aparelho e cada navegador guarda os seus, sem sincronizar entre eles.
- O arquivo já vem com os registros de 10/11/2026. Eles só são carregados num navegador que ainda não tem nada salvo.

## Fontes dos alimentos

- **TACO**, Tabela Brasileira de Composição de Alimentos, 4ª ed., NEPA/Unicamp, 2011: 591 alimentos.
- **USDA**, National Nutrient Database for Standard Reference, Release 28: 48 alimentos que a TACO não traz, como macarrão cozido, whey, atum e iogurte grego.

Os valores são médias por 100 g. Para produtos de marca, o rótulo da embalagem é o mais exato: cadastre em Ajustes → Meus alimentos.
